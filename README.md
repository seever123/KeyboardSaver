# **The problem most of us run into daily**

When you switch between different languages to write, i.e English, Arabic, and Kurdish Sorani, it's easy to type an entire message on the wrong keyboard layout. The result: a line of unreadable gibberish that has to be retyped from scratch; Costing time, focus, and sometimes the accuracy of what you were trying to say.
__________________________________

### **What The index.HTML File Gives You**

Keyboard Saver which is a browser-based tool that recovers text typed on the wrong keyboard layout. Paste the garbled text → the tool detects the mismatch → it returns the correct English, Arabic, and Kurdish Sorani output. In under a second.
__________________________________
### **Why it's safe and simple to deploy**

• Single HTML file. No installation. No server required.

• Nothing is sent anywhere; all processing happens locally in the browser. Zero data transmitted.

• Works on any device, in any modern browser, without IT involvement from the user's side.

• Can be hosted on our intranet, SharePoint, or any internal web server in a matter of minutes.
